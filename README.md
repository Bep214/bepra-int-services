# Claude Skills for Small Business

A free, curated list of the most useful Claude skills for running a small or medium business. No code. No jargon. Just the ones worth your time, what each does, and where to get it.

Put together by [BEPRA Intelligence](https://bepra-int.com): websites, AI CRMs, custom software and AI agents for established firms.

---

## What's a skill?

A skill is a saved capability. One word, and Claude stops being a general assistant and becomes a specialist. A proposal writer. A spreadsheet builder. A website auditor.

Most people use Claude like a chatbot. The owners pulling ahead have given it jobs.

**The best part:** four of these are built by Anthropic and already switched on for anyone on a paid Claude plan. You probably have them right now and didn't know. The rest are free, open-source community skills.

---

## How skills work

1. **Pick a skill** — each one is a saved set of instructions for a task.
2. **Say the word** — mention it and Claude switches into that specialist.
3. **It does the job** — the spreadsheet, the audit, the email sequence, done.
4. **Reuse forever** — same quality every time, no re-explaining.
